[Kinex](/docs/) connects a coding agent to robots and simulators. [ABB RobotStudio](https://www.abb.com/global/en/areas/robotics/products/software/robotstudio-suite/robotstudio-desktop) provides robot simulation and offline programming. This recording shows Kinex onboarding an existing RobotStudio setup and using an ABB IRB 1200 to sort six blocks by color.

## What the video shows

The station and local bridge are already running when the recording begins.

1. **Onboarding.** Kinex launches with GPT-6-Astra, high reasoning effort, and auto mode. It inspects the existing bridge, prepares device profiles and drivers, and verifies the connection.
2. **Sorting.** Kinex writes and runs a Python routine that reads the live scene, moves each block into its matching bin, and checks each placement.
3. **Verification.** Kinex confirms six correctly sorted blocks, zero in the wrong bin, and no object held, then reports the saved station and results.

The task uses simulator metadata for object colors and positions, with simulated suction attachment.
