## ROS 2 setup

For ROS 2 hardware, Kinex uses the [`onboard-ros2` skill](https://github.com/stacx-lab/kinex/blob/e6cc9defc51a8ca362b056867e759a7053cdc3d8/packages/setup/assets/builtin/skill/onboard-ros2/SKILL.md):

- **Packages.** It reuses installed ROS packages, then prefers official apt packages. It builds from source when needed or requested.
- **Dependencies.** When installation requires `sudo`, it provides the commands and target host for you to run them on.
- **Drivers.** Each device gets a versioned driver bundle; a failed rebuild preserves the working version. Verification records measurements from live ROS interfaces.

For hardware supervision, individual device registration and calibration, see [Onboarding & calibration](/docs/onboarding/).
